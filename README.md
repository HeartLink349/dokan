# دكان الحارة — Day 1

لعبة إدارة محل بقالة مصرية مبنية بـ Next.js وReact وTypeScript. هذه ليست واجهة ثابتة: اليوم الأول مسار لعب كامل من افتتاح المحل إلى تقرير النتائج، مع مخزون واقتصاد وفصال وسمعة وحفظ محلي.

## التشغيل

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. للبناء الإنتاجي:

```bash
npm run build
npm start
```

> عند غياب `node` أو `npm` من PATH، شغّل Node.js المثبّت على النظام أو أضفه إلى PATH أولًا.

## ما يتضمنه اليوم الأول

- 37 زبونًا محددًا بالاسم، لا نسخ مولّدة من نفس الشخصية.
- 10 أنواع سلوك مصرية: الحاج، الفصال، ربة البيت، الطفل، المستعجل، العصبي، حساس السعر، حساس الجودة، الموظف والعميل الدائم.
- آلة حالات للعميل: دخول → تفقد → طلب → فصال/شراء → تجهيز → دفع → رضا أو مغادرة.
- سلال متعددة المنتجات، ميزانيات، صبر، رضا، حساسية سعر، احتمالية فصال وعودة.
- ثلاثة عروض سعر لكل عملية: السعر الكامل، خصم بسيط، وعرض الزبون.
- مخزون حقيقي، إنذار مخزون منخفض، وتوريد بسعر التكلفة.
- احتساب المبيعات والتكاليف والخصومات وصافي الربح والسمعة والرضا والعملاء المحتمل عودتهم.
- تقرير نتائج Day 1 مع أفضل وأقل منتج مبيعًا.
- حفظ تلقائي في Local Storage، وإعدادات للصوت وجودة الأداء.

## البنية

```text
app/
├── page.tsx                    # واجهة اللعبة المركبة فقط
└── game/
    ├── config.ts               # إعدادات المدة والاختصارات والحفظ
    ├── types.ts                # نماذج المنتجات، العميل، الحالة والاقتصاد
    ├── core/
    │   ├── game.ts             # Game / customer-state / economy / inventory rules
    │   ├── save.ts             # SaveManager
    │   └── audio.ts            # AudioManager
    ├── data/
    │   ├── products.ts         # Product catalog
    │   ├── customers.ts        # Day 1 customer profiles
    │   └── dialogue.ts         # Data-driven Egyptian dialogue
    ├── hooks/useDokanGame.ts   # React orchestration and lifecycle cleanup
    └── locales/ar-EG.ts        # بداية نظام localization
```

إضافة منتج أو عميل أو جمل جديدة تتم من مجلد `app/game/data`، دون تعديل منطق البيع أو الواجهة الأساسية.

## التحكم

- لمس/نقر: كل أزرار البيع، الفصال، التوريد والإعدادات.
- لوحة المفاتيح: `Enter` للبيع، `Space` للفصال، السهمان ↑↓ لتغيير عرض السعر، `Esc` لإغلاق اللوحات.
- على الهاتف بالوضع الطولي: يظهر تنبيه تدوير احترافي، وتبقى حالة اللعب محفوظة عند العودة للوضع الأفقي.

## الفن والاستجابة

`public/store-scene.png` هو مشهد المتجر معروض بنسبة أبعاد ثابتة عبر `object-fit: cover` لتجنب التمديد أو التشويه. شخصية الزبون، الفقاعات واللوحات طبقات تفاعلية منفصلة فوق الخلفية. الواجهة تستخدم حاويات مرنة، مساحات ديناميكية، safe viewport units، ونمط أداء منخفض لتقليل الحركات على الأجهزة الأضعف.
